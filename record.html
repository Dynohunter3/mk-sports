How to check it yourself

  1. Open a Published link. The commit's football_predictions.json holds the prediction exactly as it was published, with the time it was made.
  2. The run link opens the GitHub Actions run that published it; GitHub records when that run happened. A commit's own date is written by whoever makes it, so the run is the stronger evidence.
  3. The predictions branch history keeps every run's file. It is added to, never rewritten.

The public history starts on 26 November 2026. Predictions graded before then were published too, but each run used to replace the previous one, so they have no commit to link.

Predictions are for information and entertainment only and are not betting advice. Even the strongest calls were wrong about a quarter of the time in testing.
